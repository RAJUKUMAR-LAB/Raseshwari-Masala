## 📖 About Raseshwari Spices

**Raseshwari Foods Pvt. Ltd.** is an authentic spice manufacturing firm rooted in **Sitamarhi, Bihar**—the cultural heart of Mithilanchal. Unlike modern commercial factories that utilize high-RPM metal pulverizers reaching 80°C and burning volatile essential oils, Raseshwari preserves tradition with **slow, cool traditional stone-grinding (< 38°C)**.

- **100% Purity Guarantee**: Zero chemical colors, starch, metanil yellow, or fillers.
- **Cold Stone Milling**: Retains maximum curcumin, natural aroma, and medicinal volatile oils.
- **Direct Mill Packaging**: Sourced directly from certified farmer clusters, ground, hermetically sealed, and dispatched directly from Sitamarhi.

## ✨ Key Features & Capabilities

- 🛒 **Interactive Product Catalog**: Instant size switcher (50g, 100g, 200g, 500g, 1kg) with real-time pricing and dynamic savings calculations.
- 🛍️ **Cart & Slide Drawer**: Seamless cart management with auto-save across sessions, volume discounts, and free shipping thresholds.

## 🚀 How to Run Locally

### Option 1: Python Built-in Server (Recommended)
1. Open PowerShell or Terminal in the project root:
   ```bash
   cd c:\rajeshwarimasala
   ```
2. Start the local server:
   ```bash
   python server.py
   ```
3. Open your browser and navigate to:
   ```text
   http://localhost:8888
   ```

### Option 2: VS Code Live Server
- Right-click `index.html` in VS Code and select **"Open with Live Server"**.

### Option 3: Direct File Opening
- Double-click `index.html` to open directly in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).
